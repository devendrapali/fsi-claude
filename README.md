# FSI website: Elementor Pro import files

Built from the client design (`assets/design-reference.jpg`).

| File | What it is | Where to import |
|---|---|---|
| `fsi-global-kit.zip` | Global colors, global fonts, theme styles (headings, buttons, forms, images), layout width, helper CSS | **Elementor › Tools › Import/Export Kit › Import a Kit**, then tick **Site Settings** only |
| `fsi-header.json` | Header (logo, menu, search, "Request a Demo") | **Templates › Saved Templates › Import Templates** |
| `fsi-footer.json` | Footer (logo, link columns, social icons) | same |
| `fsi-homepage.json` | Homepage, all 9 sections | same |
| `assets/*.jpg` | Low-resolution crops from the design, for placeholders only | Media Library |

## Requirements
- Elementor and Elementor Pro 3.20 or newer. The templates use the Nav Menu, Form, Search Form, Site Logo and Theme Builder widgets, and the kit's custom CSS needs Pro.
- **Flexbox Container** must be active (Elementor › Settings › Features). It is on by default on new sites.
- Any theme. Hello Elementor is recommended.

## Import order
1. **Import the kit first** (`fsi-global-kit.zip`) so the global colors and fonts exist before the templates refer to them.
   - Fonts used: **Poppins** for headings and buttons, and **Inter** for body text. Both are Google Fonts and Elementor loads them automatically.
2. Import `fsi-header.json` and `fsi-footer.json`. Then go to **Templates › Theme Builder**, open each one, click **Publish**, and set the display condition to **Entire Site**.
3. In the header, select your menu in the **Nav Menu** widget. Create it first under Appearance › Menus: Home, FSI Courses, The FSI Way, Professional Learning, FSI Publishing, Implementation, About FSI.
4. Upload the FSI logo under **Site Settings › Site Identity**. The header and footer Site Logo widgets use it.
5. Create a page called "Home" and click **Edit with Elementor**. Open the folder icon, go to **My Templates**, and insert **FSI – Homepage**.
   In Page Settings, set **Page Layout = Elementor Full Width** and turn on **Hide Title**. Then set it as the homepage under Settings › Reading.

## Editing tips
- **Colors and fonts are global.** Change them in Site Settings › Global Colors / Global Fonts and the whole site updates. Navy = Primary, Gold = Secondary, Bright Blue = Accent, plus FSI custom colors (Deep Navy, Light Blue Card, and others).
- **Chart (Proven Results):** each bar is an empty container. Change its **Min Height** to resize it. The scale is 1.9px per percentage point, so 62% = 118px. Edit the "62%" and "71%" headings to match.
- **Request Professional Learning form:** edit the dropdown options under Form Fields. Set the email recipient under Actions After Submit › Email.
- **Helper CSS classes** are defined in Site Settings › Custom CSS:
  - `fsi-btn-arrow` adds a trailing → to buttons that already have a leading icon.
  - `fsi-card` adds a hover lift.
  - `fsi-swoosh` adds the gold curved underline to a **Heading** widget. It is sized in em, so it scales with the font size. You can combine it with these modifiers:
    - position: `fsi-swoosh--center` or `fsi-swoosh--right`
    - width: `fsi-swoosh--short`, `fsi-swoosh--long` or `fsi-swoosh--full`
    - color: `fsi-swoosh--white` or `fsi-swoosh--navy` (the default is Global Secondary, gold)
  - `fsi-rotate` turns the chart's axis label vertical.
- **Anchor IDs** for menu or button links: `#hero`, `#professional-learning`, `#plans`, `#publishing`, `#request-demo`.

## Regenerating
Everything is generated by `src/build.py`. Edit the tokens or sections there and run `python3 src/build.py`.
